### Introduction to Computer Networks: The Basics

![[Pasted image 20260817052549.png]]
#### 1. What is a Computer Network? (Defination)

Ek simple definition se start karte hain: **"A computer network is a set of nodes connected by communication links."**

Iska matlab samajhte hain:

- **Nodes:** Koi bhi device jo data send ya receive kar sake. Examples: Computer, printer, server, smartphone, security camera, routers, switches.
    
- **Communication Links:** Yeh woh medium hai jo data ko ek node se doosre node tak carry karta hai.
    
    - **Wired Link:** Physical medium, jaise cables (e.g., Ethernet cables).
        
    - **Wireless Link:** No physical cable. Example: "Air" jo radio signals/waves ko carry karta hai (e.g., Wi-Fi, Bluetooth).

#### 2. Why do we need Networks? (Resource Sharing)

Networking ka sabse bada motive hota hai **Resource Sharing**.

- **Cost Efficiency:** Maan lo ek office me 4 computers hain. Agar har computer ke liye alag printer khareedoge, toh bahut kharcha hoga. Iske bajaye, agar sabko ek network se connect karke ek printer share kar do, toh infrastucture cost bahut kam ho jayegi.
    

#### 3. Classification of Devices

Network me devices ko main do categories me baanta gaya hai:

- **End Devices:**
    
    - Yeh communication ke **starting point** ya **end point** hote hain.
        
    - Example: Computer, Laptop, Smartphone, Tablet, Printer, Server.
        
    - Interview Tip: Jab tum interview me bologe, toh hamesha yaad rakhna ki end device ka primary kaam data create ya consume karna hota hai.
        
- **Intermediary Devices:**
    
    - Inka kaam data ko ek side se doosri side **forward** karna hota hai.
        
    - Example: Switches, Bridges, Routers, Wireless Routers.
        

### Interview Perspective (FAANG/MAANG)

Interview me basics se hi sawal shuru hote hain. Is lecture ke basis pe tumse yeh pucha ja sakta hai:

1. **Explain the difference between End Devices and Intermediary Devices?** (Answer: Source/Destination vs Forwarding capability)
    
2. **Why is a switch or router considered a node?** (Answer: Kyunki woh bhi data send/receive kar sakte hain, chahe woh end-user data na ho, but control/management data toh process karte hain)
