### COMPONENTS OF COMPUTER NETWORK

### 1. Three Main Components of a Computer Network

Kisi bhi computer network me ye teen cheezein zaroor hoti hain:

#### A. Nodes (Devices)

- **End Nodes (Devices):** Jo communication start ya end karte hain. (e.g., Computer, Smartphone, VoIP Phones, Security Cameras, Printer).

![[Pasted image 20260817103304.png]]

- **Intermediary Nodes (Devices):** Jo data ko sirf forward karte hain, end nodes ke beech me hote hain. (e.g., Switch, Router, Hub, Repeater, Firewall, Cell Phone Tower).
    
![[Pasted image 20260817103318.png]]

#### B. Media (Link)

Data ek node se doosre node tak kaise jayega, us raste ko "Media" ya "Link" kehte hain.

- **Guided (Wired):** Cables use hoti hain.
    
    - **Ethernet Cable (Twisted-pair):** Standard connection ke liye. Do types: **Straight-through** (different devices ke liye, e.g., PC-Switch) aur **Crossover** (same devices ke liye, e.g., Switch-Switch).
![[Pasted image 20260817103605.png]]
    - **Fiber Optic:** Light pulses use hoti hain; **Fastest** wired medium.
![[Pasted image 20260817103625.png]]
    - **Coaxial:** Audio/Video ke liye (e.g., Set-top box). ==***CARRIES THE DATA IN THE FORM OF ELECTRICAL SIGNALS***==
![[Pasted image 20260817103714.png]]
    - **USB(*UNIVERSAL SERIAL BUS*) Cable:** Local device connection ke liye.
![[Pasted image 20260817103921.png]]
- **Unguided (Wireless):** Air medium ka use hota hai.
    
    - ==**Infrared:** Short range (e.g., TV Remote).==
        
    - ==**Radio Waves:** Wi-Fi/Bluetooth.==
        
    - ==**Microwaves:** Long distance (e.g., Cell phone towers).==
        
    - **Satellite:** Global/Ultimate long-distance.

### 2. Interview Perspective (MAANG Focus)

- **Ethernet Cables:** Interviewer pucha sakta hai ki "Kab Straight-through aur kab Crossover cable use karte hain?"
    
    - _Ans:_ Straight-through for different devices (DTE to DCE), Crossover for same devices (DTE-DTE or DCE-DCE).
        
- **Guided vs. Unguided:** Networking fundamentals me inka basic classification pucha jata hai. Guided = Cable-based (controlled path), Unguided = Wireless (Air-based).
    
- **Fiber Optic:** Hamesha yaad rakhna ki yeh light pulses use karta hai, isi liye yeh bandwidth aur speed me baaki sabse behtar hai.
